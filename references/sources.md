# 方法来源与验证范围

本母包由尼尔.S 与 Codex 从 的宠物角色定制试验中提炼，版本 0.1.0（2026-10-26）。Tom 是测试实例，不是角色模板；母包无 Tom 私人照片、角色图、文章全文或 PPT 大文件。

- handraw：yang0，https://github.com/yang0/handraw-style ，六种初始画风的选款对照。仅保留编号与重写的视觉要求，无上游代码或样图。
- 尼尔.S 的 laien-cartoon：角色身份／画风分离、携带参考、动作服务观点的方法。没有复制莱恩资产；不继承其犬形、毛色、搭档或视频链路。
- 尼尔.S 的 vox-ppt-design：内容组织、原生可编辑对象与输出验证。为不同宠物重写适配，不依赖固定纸感配色或母本安装。
- S32 travel-memory-card-duo：https://github.com/carolinaaafy/travel-memory-card-duo/blob/9348e16ab7200b8f36c2d3c257fc6fae6bf8e38e/SKILL.md
